# References and Citations

This document compiles the verifiable primary sources, NASA research publications, and open API documentation informing the ASTROCARE prototype design.

---

### 1. NASA Human Research Roadmap (HRR)
- **Title / Topic**: Risk of Performance Decrements and Adverse Health Outcomes Resulting from Sleep Loss, Circadian Desynchronization, and Work Overload (Sleep Risk)
- **URL**: https://humanresearchroadmap.nasa.gov/
- **What this source supports**: Establishes NASA's operational framework recognizing sleep deficiency, circadian misalignment, and heavy workload as critical operational risks that impair astronaut cognitive performance and mission safety.

---

### 2. NASA Open Science Data Repository (OSDR)
- **Title / Topic**: NASA Open Science Data Repository (OSDR)
- **URL**: https://osdr.nasa.gov/
- **What this source supports**: Provides open-access spaceflight biological and physiological datasets (consolidating GeneLab and the Ames Life Sciences Data Archive) demonstrating how spaceflight environments alter human and model organism physiology.

---

### 3. NASA NTRS: Evidence Report on Sleep Loss and Work Overload
- **Title**: *Evidence Report: Risk of Performance Decrements and Adverse Health Outcomes Resulting from Sleep Loss, Circadian Desynchronization, and Work Overload*
- **Authors**: Erin E. Flynn-Evans, K. Gregory, L. Arsintescu, A. Whitmire, and L. B. Leveton (2016)
- **NTRS Document ID**: 20160003864
- **URL**: https://ntrs.nasa.gov/citations/20160003864
- **What this source supports**: Synthesizes empirical evidence showing chronic sleep debt and circadian misalignment during space missions, supporting the operational need for personalized baseline tracking and timely rest opportunities.

---

### 4. NASA NTRS: Operational Fatigue Countermeasures
- **Title**: *Crew Factors in Flight Operations IX: Effects of Planned Cockpit Rest on Crew Performance and Alertness in Long-Haul Operations* (NASA Technical Memorandum 108839)
- **Authors**: Mark R. Rosekind, Philippa H. Gander, David L. Miller, Kevin J. Gregory, Roy M. Smith, Kevin L. Weldon, Elizabeth L. Co, Donna L. McNally, and J. Victor Lebacqz (1994)
- **NTRS Document ID**: 19950006379
- **URL**: https://ntrs.nasa.gov/citations/19950006379
- **What this source supports**: Documents how structured rest countermeasures and mission schedule adjustments restore physiological alertness and task execution capability in safety-critical operational flight environments.

---

### 5. NASA DONKI API Documentation
- **Title**: NASA Space Weather Database Of Notifications, Knowledge, Information (DONKI) API
- **URL**: https://api.nasa.gov/ and https://ccmc.gsfc.nasa.gov/DONKI/
- **What this source supports**: Provides programmatic access to real-time space weather observations (including solar flare event notifications), used in ASTROCARE strictly for environmental mission context rather than individual health correlation or causal assessment.
