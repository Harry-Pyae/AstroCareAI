# ASTROCARE — References & Attributions (final)

Primary sources, NASA resources, open-source libraries, and assets used in the
prototype, with what each supports. All health observations in the app are
team-generated synthetic telemetry, labeled in-app; the sources below informed
their design and the product's scope.

---

## NASA sources

### 1. NASA Human Research Roadmap (HRR)
- **URL**: https://humanresearchroadmap.nasa.gov/
- **Supports**: the selection of tracked indicators. HRR documents sleep loss,
  circadian desynchronization and work overload, cardiovascular and bone
  changes, behavioral health, and radiation exposure as operational risks of
  long-duration spaceflight — each ASTROCARE metric maps to a documented risk.

### 2. NASA DONKI — Space Weather Database of Notifications, Knowledge, Information
- **URL**: https://ccmc.gsfc.nasa.gov/tools/DONKI/
- **Used for**: the live space-weather context card (recent solar-flare
  events with timestamps and source attribution; cached fallback when the
  feed is unavailable). Displayed as environmental context only — never
  causally linked to any health reading.

### 3. NASA Technical Reports Server (NTRS)
- **URL**: https://ntrs.nasa.gov/
- **Supports**: publications on astronaut sleep, countermeasures, and crew
  health monitoring that informed the synthetic data's realistic shapes and
  the check-in's self-report fields.

### 4. NASA Open Science Data Repository (OSDR) / Life Sciences Data Archive
- **URL**: https://osdr.nasa.gov/
- **Role**: named future integration path — the open repository where real
  (consented, public) spaceflight physiological datasets would plug into the
  same baseline pipeline. Not integrated in the prototype.

### 5. NASA Twins Study & Human Research Program publications
- **URL**: https://www.nasa.gov/hrp/
- **Supports**: the core design thesis that individual baselines matter more
  than population norms for spaceflight health monitoring.

## Fonts & assets

- **Noto Sans Myanmar** — SIL Open Font License 1.1 (bundled; license text in
  `src/assets/fonts/OFL-NotoSansMyanmar.txt`). Enables the Myanmar-language UI.
- **Icon set & brand mark** — original SVGs created by the team for this
  project (monotone 24×24 stroke set + crescent/pulse-star app icon).
- **Synthetic datasets** — generated by `src/data/generate-seeds.mjs` and
  `src/data/scenarios/generate.mjs`; provenance recorded per record
  (`synthetic_telemetry` / `user_checkin`).

## Development tooling (not part of the shipped product)

Generative AI assistants (OpenAI Codex, Anthropic Claude, Google Gemini) were
used for planning, code generation and review, and documentation drafting.
All AI-assisted code was human-reviewed, type-checked, and unit-tested. The
running application contains no AI model; all runtime explanations are
deterministic rule output.
